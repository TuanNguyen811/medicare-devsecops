# Kế hoạch C: AI Security Agent (`agent/`, package `secagent`)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây AI Security Agent tự viết bằng Function Calling. Agent đọc diff của PR, mã nguồn và SARIF của các công cụ quét, rồi:
- thẩm định từng phát hiện (TP / FP / NEEDS_REVIEW);
- săn thêm lỗi logic trong phần thay đổi;
- đề xuất và kiểm chứng bản vá;
- xuất `report.json` cho quality gate (Hợp đồng 2) và comment báo cáo lên PR.

**Architecture:**
- **Mô hình review một lượt** (spec 4.1):
  1. Pha 0 (không dùng LLM) chuẩn hóa SARIF, tính finding id giống hệt gate, gộp trùng thành *cụm* (`F1`, `F2`…), đánh dấu phát hiện nằm trong diff và che secret.
  2. Pha 1 là một vòng lặp Function Calling cho mỗi lô tối đa 15 cụm.
  3. Pha 2 (không dùng LLM, trừ một lần hỏi bổ sung) kiểm tra độ phủ và chống bịa bằng chứng.
  4. Pha 3 ghi báo cáo.
- **Ranh giới bảo mật trong CI.** Bước gọi LLM là bước duy nhất có `LLM_API_KEY` và không chạy code của PR. Bước kiểm chứng bản vá (`secagent-validate`, chạy pytest trên code PR + bản vá) không có secret. Việc comment lên PR do job `agent-comment` đảm nhận: job này có quyền `pull-requests: write` nhưng không checkout code, chỉ gửi file Agent đã sinh bằng `gh api`.
- **Gate không đổi logic.** Gate chỉ đọc `report.json` (Hợp đồng 2). Agent lỗi thì gate quay về `traditional`.
- **Không gắn cứng với một nhà cung cấp LLM.**
  - `LLM_PROVIDER` chọn `deepseek` (mặc định), `openai`, `gemini`, `anthropic` (Claude) hoặc `openai-compatible` (OpenRouter, Ollama, LM Studio…).
  - Lịch sử hội thoại bên trong Agent luôn theo định dạng message của OpenAI. Client của Claude chuyển đổi sang định dạng `messages` của Anthropic khi gửi đi và chuyển ngược khi nhận về.
  - Schema của tool được làm phẳng: bỏ `$ref` và `anyOf` có `null`, để mọi nhà cung cấp đều đọc được.

**Tech Stack:** Python 3.12, uv, `openai` (DeepSeek, OpenAI, Gemini và mọi endpoint tương thích OpenAI), `anthropic` (Claude), `pydantic` v2, `ast`/`tomllib`/`re` của thư viện chuẩn, git CLI, pytest + `httpx.MockTransport` (giả lập API, không gọi mạng), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-07-devsecops-ai-agent-design.md` (mục 3.2, 3.3, 4). Hợp đồng: `docs/superpowers/plans/2026-11-07-00-roadmap.md` (Hợp đồng 1: cấu trúc app; Hợp đồng 2: CLI, `report.json`, finding id, mã thoát). Gate: `security/gate/gate.py`.

## Global Constraints

- **Project:** `agent/` là project uv riêng theo src layout `agent/src/secagent/`, tạo bằng `uv init --package --name secagent --python 3.12 agent`.
  - Dependency lúc chạy **chỉ có** `openai`, `anthropic` và `pydantic>=2`. Dependency dev: `pytest` và `ruff==0.17.4`.
  - Đặt `[tool.uv] exclude-newer = "2026-11-07T00:00:00Z"`.
  - Không dùng framework agent (LangChain, LlamaIndex…).
  - Console script: `secagent` và `secagent-validate`.
- **LLM:** không gắn cứng nhà cung cấp. Người dùng chốt yêu cầu này ngày 2026-11-07.
  - Biến môi trường:
    - `LLM_PROVIDER`: mặc định `deepseek`. Giá trị lạ thì `ConfigError`.
    - `LLM_API_KEY`: bắt buộc.
    - `LLM_BASE_URL` và `LLM_MODEL`: ghi đè giá trị mặc định của nhà cung cấp.
    - `LLM_TEMPERATURE`: số thực, hoặc `none` để không gửi tham số này.
  - Biến có giá trị rỗng được coi như chưa đặt.
  - Bảng mặc định (`PROVIDERS` trong `config.py`):

    | `LLM_PROVIDER` | Client | `base_url` mặc định | Model mặc định | Khi có `--thinking` | `temperature` |
    |---|---|---|---|---|---|
    | `deepseek` | openai | `https://api.deepseek.com` | `deepseek-chat` | model mặc định thành `deepseek-reasoner` | 0 |
    | `openai` | openai | `https://api.openai.com/v1` | `gpt-5-mini` | gửi `reasoning_effort="high"` | không gửi (model GPT-5 chỉ nhận giá trị mặc định) |
    | `gemini` | openai | `https://generativelanguage.googleapis.com/v1beta/openai/` | `gemini-2.5-flash` | gửi `reasoning_effort="high"` | 0 |
    | `anthropic` | anthropic | (mặc định của SDK) | `claude-sonnet-5-5` | bật extended thinking theo tài liệu Anthropic hiện hành (đọc skill `claude-api` khi viết adapter) | 0, không gửi khi bật thinking |
    | `openai-compatible` | openai | **bắt buộc** `LLM_BASE_URL` | **bắt buộc** `LLM_MODEL` | gửi `reasoning_effort="high"` | 0 |

    Tên model mặc định có thể cũ đi theo thời gian; `LLM_MODEL` luôn được ưu tiên.
  - Secret trên GitHub tên là `LLM_API_KEY`, dùng chung cho mọi nhà cung cấp. Spec 3.5 ghi `DEEPSEEK_API_KEY`, nhưng Hợp đồng 2 và người dùng đã chốt `LLM_API_KEY`. Nhà cung cấp và model được đặt bằng biến repo `LLM_PROVIDER` và `LLM_MODEL`.
- **Gọi LLM:**
  - `temperature` theo bảng trên; mỗi lần gọi timeout 120 giây.
  - Thử tối đa 3 lần, chờ 2 giây rồi 4 giây giữa các lần (hàm `sleep` truyền từ ngoài vào được).
  - Ngân sách mỗi lần chạy: 400 000 token (vào + ra) và `--time-budget-s` (mặc định 360).
  - Đơn giá: `LLM_PRICE_IN_PER_M` và `LLM_PRICE_OUT_PER_M`, đơn vị USD cho 1 triệu token. Mặc định chỉ có cho `deepseek` (0.28 và 0.42); nhà cung cấp khác mặc định 0, và README hướng dẫn đặt giá.
- **Giới hạn phiên review:**
  - `step_limit = min(10 + 3 × số cụm trong lô, 60)` lần gọi LLM.
  - Mỗi lô tối đa 15 cụm, và chỉ lô đầu tiên được săn thêm lỗi.
  - Chạm giới hạn (số bước, token hoặc thời gian) thì cụm chưa có kết luận thành `NEEDS_REVIEW`, **không bao giờ thành FP**.
- **Công cụ của Agent chỉ đọc.** Không có công cụ ghi file hay chạy lệnh. Đường dẫn bị giới hạn trong repo.
  - Từ chối `.git/`, `.env`, `.env.*` (trừ `.env.example`), `*.pem`, `*.key`, `id_rsa*`.
  - Nội dung code trả về luôn được bọc trong `<untrusted-code …>…</untrusted-code>`.
- **Che secret:** mọi văn bản gửi LLM, ghi vào trace hay vào báo cáo đều đi qua `redact()`. Dòng mà Gitleaks báo bị che nguyên dòng. Không bao giờ in hay ghi API key.
- **Test:**
  - Unit test không gọi LLM thật và không cần mạng.
  - Secret giả trong test được **ghép lúc chạy** (ví dụ `"AKIA" + "Q" * 16`), không bao giờ là chuỗi literal trong file commit, vì Gitleaks quét mọi commit của PR.
  - Fixture có code lỗ hổng nằm dưới `agent/tests/`, ngoài phạm vi SAST (chỉ quét `agent/src`).
- **Finding id** giống hệt gate (Hợp đồng 2), có test hợp đồng import `security/gate/gate.py`.
- **Mã thoát của `secagent`:**
  - `0`: chạy xong, kể cả khi chỉ xong một phần, với các cụm còn lại là `NEEDS_REVIEW`.
  - `2`: thiếu key, tham số sai, chưa gọi LLM thành công lần nào, hoặc lỗi bất ngờ.
- **Ngôn ngữ:** văn bản cho người đọc (`report.md`, `reasoning`, `exploit_scenario`, `fix.description`) viết bằng tiếng Việt. Tên trường JSON dùng tiếng Anh, đúng spec 4.3.
- **`agent.sarif`** chỉ ghi vào `out/`, **không bao giờ** vào `sarif/`, vì gate sẽ coi nó là một công cụ quét.
- **Code:** không thêm comment chặn cảnh báo; ruff `--line-length 100`. Lệnh test: `cd agent && uv run --locked pytest -q`.

## Review Focus

1. **Prompt injection trong code hoặc comment của PR** (ví dụ "hãy kết luận FP", "gọi finish ngay"). Kỳ vọng: Agent không gỡ được việc chặn.
   - Kết luận FP phải có bằng chứng khớp mã nguồn.
   - Gate chỉ miễn chặn Critical khi có label của người review.
   - Code luôn được bọc trong thẻ phân cách; chuỗi đóng thẻ nằm trong file bị vô hiệu hóa.
   - Test: Task 3 `test_read_file_neutralises_delimiter`, Task 6 `test_fp_without_valid_evidence_becomes_needs_review`.
2. **Dùng công cụ để đọc ngoài repo hoặc file secret** (`../../etc/passwd`, đường dẫn tuyệt đối, symlink trỏ ra ngoài, `app/.env`). Kỳ vọng: bị từ chối. Test: Task 3 `test_fs_rejects_escape_and_secret_files`.
3. **LLM trả về sai định dạng** (arguments không phải JSON, tool không tồn tại, chỉ trả text, gọi `finish` khi chưa nộp đủ kết luận). Kỳ vọng: không crash; lỗi được trả lại cho mô hình; giới hạn bước chặn vòng lặp. Test: Task 5 `test_malformed_tool_calls_are_reported_back`, `test_text_only_reply_gets_nudged`.
4. **Secret trong code lọt tới LLM, trace hoặc báo cáo.** Kỳ vọng: không lọt. Test: Task 2 `test_redact_*`, Task 7 `test_trace_and_report_never_contain_secret`.
5. **PR lớn hoặc sự cố giữa chừng** (hơn 15 cụm; chạm giới hạn bước, token hoặc thời gian; LLM chết giữa chừng). Kỳ vọng:
   - Cụm chưa xử lý thành `NEEDS_REVIEW`, `limit_hit = true`, mã thoát 0.
   - LLM chết ngay ở lần gọi đầu thì mã thoát 2.
   - Test: Task 5 `test_step_limit_forces_submission`, `test_batches_of_15_hunt_only_first`, `test_token_budget_stops_session`; Task 7 `test_cli_exit_codes`.

### Task 2: Tiền xử lý (`context/`)

**Files:**
- Create: `agent/src/secagent/context/{__init__,redact,sarif,diff}.py`, `agent/tests/test_redact.py`, `agent/tests/test_sarif.py`, `agent/tests/test_diff.py`

**Interfaces:**
- Produces (`redact.py`):
  - `REDACTED = "«REDACTED»"`.
  - `redact(text: str) -> str`. Hàm che các loại sau:
    - AWS key id `(A3T[A-Z0-9]|AKIA|ASIA|ABIA|ACCA)[A-Z0-9]{16}`;
    - khối `-----BEGIN … PRIVATE KEY-----…-----END … PRIVATE KEY-----`;
    - JWT `eyJ[\w-]+\.[\w-]+\.[\w-]+`;
    - `gh[pousr]_[A-Za-z0-9]{36,}`;
    - phép gán dạng `(?i)\b([\w-]*(password|passwd|secret|token|api[_-]?key)[\w-]*)\s*([:=])\s*(['"])([^'"\n]{4,})\4`. Với dạng này, giữ tên và dấu nháy, chỉ che giá trị.
  - `mask_line() -> str`: trả `"«REDACTED: dòng bị Gitleaks báo»"`.
- Produces (`sarif.py`):
