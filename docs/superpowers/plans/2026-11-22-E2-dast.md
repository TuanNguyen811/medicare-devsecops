# Giai đoạn 2: DAST với OWASP ZAP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (người dùng chọn Native: Claude tự làm, review toàn nhánh ở cuối). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mỗi PR được ZAP quét động bằng 5 vai trò, có đăng nhập. Kết quả là `sarif/zap.sarif` mà gate và AI Agent đọc như mọi công cụ quét khác. Cùng bộ script dùng lại được cho deploy (giai đoạn 3) và benchmark (giai đoạn 5).

**Architecture:**
- **Trong container app** (không cần cài gì trên máy): `export_routes.py` xuất `openapi.json` và `routes.json`, gồm method, đường dẫn mẫu và file/dòng của hàm xử lý.
- **Trong container ZAP**, cùng mạng Docker với app:
  - `login.py` đăng nhập lấy cookie phiên và CSRF token;
  - `zap.sh -autorun zap-plan.yaml` gắn cookie/token vào mọi request, rồi spider, import OpenAPI, active scan và xuất JSON.
- `zap2sarif.py` gộp báo cáo của 5 vai trò thành một `zap.sarif`. Mỗi kết quả có `relatedLocations` trỏ về hàm xử lý route, nên phần chống bịa của Agent giữ nguyên độ chặt (spec bổ sung 5.3).

**Tech Stack:**
- ZAP (image ghim theo digest), ZAP Automation Framework.
- Python 3 thư viện chuẩn cho `login.py` và `zap2sarif.py`. Hai file này chạy trong container ZAP và trên runner, không phụ thuộc gì.
- GitHub Actions dạng ma trận.

**Spec:** `docs/superpowers/specs/2026-11-21-ops-dast-engine-design.md` mục 5. Hợp đồng 2 trong `docs/superpowers/plans/2026-11-07-00-roadmap.md`.

## Global Constraints

- Tên công cụ là `zap`, tên file `sarif/zap.sarif`, category upload SARIF là `dast`.
- `ruleId` = pluginId của ZAP.
- Mức độ theo risk của ZAP, ghi vào `properties.security-severity` của rule:

  | Risk | Mức độ | `security-severity` |
  |---|---|---|
  | High | HIGH | `8.0` |
  | Medium | MEDIUM | `5.0` |
  | Low | LOW | `2.0` |
  | Informational | bỏ, không đưa vào SARIF | — |

- Vị trí: `artifactLocation.uri = "dast:<METHOD> <đường dẫn mẫu>"`, không có `startLine`. Finding id = `zap:<pluginId>:dast:<METHOD> <đường dẫn mẫu>:0`.
- Đường dẫn mẫu = path của route FastAPI khớp với URL (ví dụ `/patients/{patient_id}`). Không khớp route nào thì thay các đoạn toàn số bằng `{id}`. Bỏ query string.
- `properties`: `roles` (sắp xếp), `cwe`, `param`, `evidence` (cắt 200 ký tự), `confidence`.
- 5 tài khoản demo: `admin` (ADMIN), `letan1` (RECEPTIONIST), `bacsi1` (DOCTOR), `yta1` (NURSE), `benhnhan1` (PATIENT). Mật khẩu lấy từ `DEMO_PASSWORD`, không bao giờ in ra.
- **Loại khỏi phạm vi quét:**
  - `/logout`;
  - `/account/password`;
  - `POST /login` (active scan không được làm khóa tài khoản theo R-07);
  - `/static/`.
- **Fail-safe:**
  - job `dast` nằm trong danh sách job bắt buộc `success` của `quality-gate`;
  - mỗi vai trò thử lại 1 lần;
  - thiếu báo cáo của bất kỳ vai trò nào thì `dast` thất bại.
- Job DAST chạy code PR trên runner, **không tham chiếu secret nào**, `persist-credentials: false`, quyền `contents: read`.
- Tool versions ở một chỗ: `security/tool-versions.env`, thêm `ZAP_IMAGE=ghcr.io/zaproxy/zaproxy@sha256:<digest>`.
- Ghi file bằng Python dùng `encoding="utf-8", newline=""`. Commit theo Conventional Commits, kết thúc bằng `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Test chạy bằng `uv run --project app pytest security/dast/tests -q` (môi trường của app có FastAPI). Sửa agent thì chạy `uv run --project agent --locked pytest -q agent/tests`; sửa gate thì chạy `uv run --no-project --python 3.12 --with pytest pytest security/gate/tests -q`.

## Review Focus

1. **Cookie hết hạn hoặc bị đăng xuất giữa lúc quét** thì quét tiếp như khách và báo sai. `/logout` bị loại, cookie được gắn cứng cho mọi request. Kiểm tra bằng số URL có xác thực trong báo cáo khi chạy thật (Task 6).
2. **ZAP báo nhiều cảnh báo Low/Medium trên bản sạch** làm Agent phải thẩm định lại ở mọi PR. Đo trên `main` ở Task 6, ghi vào `docs/baseline-scan.md`. Bản sạch phải có 0 cảnh báo High.
3. **URL không khớp route nào** (static, 404): vẫn ra SARIF với đường dẫn chuẩn hóa, không có related location, không crash. Test ở Task 2.
4. **Báo cáo ZAP rỗng hoặc hỏng** của một vai trò: `zap2sarif` thoát khác 0 và job `dast` thất bại (fail-safe), không bao giờ ra SARIF rỗng như thể "không có phát hiện". Test ở Task 2.
5. **Finding `zap` bị lọc mất** vì không nằm trong file nào của diff: gate và Agent phải luôn giữ. Test ở Task 4.

- CLI: `python export_routes.py <out_dir>`.

### Task 2: `zap2sarif.py`

**Files:** Create `security/dast/zap2sarif.py`, `security/dast/tests/test_zap2sarif.py`, `security/dast/tests/fixtures/zap-DOCTOR.json`, `zap-PATIENT.json`, `routes.json`.

**Interfaces:**
- `template(path: str, routes: list[dict], method: str) -> tuple[str, dict | None]`: đường dẫn mẫu cùng route khớp (hoặc `None`).
- `convert(reports: dict[str, dict], routes: list[dict]) -> dict`: gộp theo (pluginId, METHOD, đường dẫn mẫu); `roles` là hợp các vai trò. Mỗi result có:
  - `message.text` = tên cảnh báo;
  - `properties` như Global Constraints;
  - `relatedLocations` = `[{"physicalLocation": {"artifactLocation": {"uri": route.file}, "region": {"startLine": route.line}}}]` khi khớp route.
- Rule: `id` = pluginId, `name`, `properties.security-severity`, `properties.tags = ["security", "CWE-<cweid>"]` (bỏ tag CWE khi `cweid` ≤ 0).
- CLI: `python zap2sarif.py --routes routes.json --out zap.sarif <role>=<report.json> ...`. Thoát `1` nếu một báo cáo không đọc được hoặc không có khóa `site`.

- [ ] Viết test:
  - `test_merges_roles_and_maps_route`: cùng một cảnh báo SQLi ở `/patients/12` (DOCTOR) và `/patients/7` (PATIENT) → đúng 1 result, uri `dast:GET /patients/{patient_id}`, `roles == ["DOCTOR", "PATIENT"]`, related location trỏ đúng file/dòng trong `routes.json`.
  - `test_severity_and_informational_dropped`: High → `8.0`, Low → `2.0`; cảnh báo Informational không có trong SARIF.
  - `test_unmatched_url_normalised`: `/static/x/123` → `dast:GET /static/x/{id}`, không có `relatedLocations`.
  - `test_finding_id_matches_gate`: chạy `security/gate/gate.py` `load_sarif` trên SARIF sinh ra, rồi kiểm tra `Finding.id` == `"zap:40018:dast:GET /patients/{patient_id}:0"` và severity HIGH.
  - `test_cli_fails_on_broken_report`: một báo cáo là `"{}"` hoặc không tồn tại → thoát `1`, không tạo file.
- [ ] Chạy, phải FAIL. Cài đặt. Chạy, phải PASS. Commit `feat(dast): gộp báo cáo ZAP các vai trò thành SARIF`.

### Task 3: `login.py`, `zap-plan.yaml`, `run-dast.sh`, phiên bản ZAP

**Files:** Create `security/dast/login.py`, `security/dast/zap-plan.yaml`, `security/dast/run-dast.sh`, `security/dast/tests/test_login.py`. Modify `security/tool-versions.env` (thêm `ZAP_IMAGE`), `.gitignore` (thêm `dast-out/`).

**Interfaces:**
- `login.py`:
  - `extract_csrf(html: str) -> str | None`: input `name="csrf_token"` hoặc thẻ meta `csrf-token`.
  - `session_cookie(headers) -> str | None`: giá trị `medicare_session` lấy từ `Set-Cookie`.
  - CLI: `python3 login.py <base_url> <username>`, mật khẩu đọc từ biến môi trường `DEMO_PASSWORD`. In ra stdout hai dòng `ZAP_COOKIE=medicare_session=<...>` và `ZAP_CSRF=<token>`.
  - Các bước: GET `/login`, POST form (không tự đi theo redirect; phải nhận 303), rồi GET `/` lấy token đã xoay (meta `csrf-token`).
  - Sai mật khẩu hoặc không có cookie → thoát `1`, không in mật khẩu.
- `zap-plan.yaml` (Automation Framework, đọc biến môi trường `${TARGET}`, `${ZAP_COOKIE}`, `${ZAP_CSRF}`, `${ROLE}`):
  - context có `includePaths: ${TARGET}.*` và các `excludePaths` như Global Constraints;
  - job `replacer` gắn header `Cookie` và `X-CSRF-Token` cho mọi request;
  - `openapi` import `/zap/wrk/openapi.json` với `targetUrl: ${TARGET}`;
  - `spider` (tối đa 2 phút);
  - `activeScan` (tối đa 5 phút);
  - `report` dạng `traditional-json` ra `/zap/wrk/out/zap-${ROLE}.json`.
- `run-dast.sh --target <url> --network <docker-network> --work <dir> [--roles "ADMIN ..."]`:
  - `<dir>` chứa sẵn `openapi.json`, `routes.json`; script chép `login.py` và `zap-plan.yaml` vào đó;
  - mỗi vai trò: `docker run --rm --network <net> -e DEMO_PASSWORD -v <dir>:/zap/wrk $ZAP_IMAGE python3 /zap/wrk/login.py ...`, rồi `docker run ... zap.sh -cmd -autorun /zap/wrk/zap-plan.yaml`;
  - mã thoát 0 hoặc 2 của ZAP là chạy xong (2 = có cảnh báo của job). Báo cáo phải tồn tại, không thì thử lại 1 lần, rồi mới tính là lỗi;
  - cuối cùng gọi `zap2sarif.py` ghi `<dir>/zap.sarif`;
  - thoát khác 0 nếu bất kỳ vai trò nào thất bại.
- [ ] Test `test_extract_csrf_from_form_and_meta`, `test_session_cookie_from_headers`. Chạy FAIL, cài đặt, PASS.
- [ ] Lấy digest của ZAP stable (`docker image inspect`), ghi `ZAP_IMAGE` vào `tool-versions.env`.
- [ ] Commit `feat(dast): đăng nhập theo vai trò và kế hoạch quét ZAP`.
